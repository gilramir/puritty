puritty reads an APC's, a PM's and an SOS's text as UTF-8, as it reads an
OSC's: bytes from 0x80 are parts of characters, and only ESC \, CAN or SUB
end the string (the code review's VP9, docs/vt-core.md VC73). Ghostty's
stream decodes UTF-8 outside strings but runs these strings through the
8-bit DEC table, where 0x80-0x9F are C1 controls that end the string and
0xA0-0xFF are dropped: 한 (ED 95 9C) ends the APC at 0x95, and the rest
prints. ghostty.txt is to be pinned where the oracle builds (nene):
./harness/replay.py -f apc-utf8-text --update --side ghostty.
