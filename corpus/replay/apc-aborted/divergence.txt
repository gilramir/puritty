A raw byte from 0x80 to 0x9F inside an APC, PM or SOS string is that
string's text in puritty, as in an OSC: in UTF-8 such a byte is part of a
character, never a C1 control (the code review's VP9, docs/vt-core.md
VC73). Ghostty runs these strings through the 8-bit DEC table, where the
byte ends the string and is dispatched as C1; so here the string goes on
to the next ESC and what Ghostty prints after the byte is not printed.
ghostty.txt is the expected.txt both sides agreed on before VC73.
