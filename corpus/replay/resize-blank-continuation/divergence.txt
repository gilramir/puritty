Ghostty's reflow joins a line to the next when the line's last row is blank
and continues a wrapped row: `reflowRow` skips a blank row without counting
a line's end when the row is a wrap continuation, so the next line is
written on in the same row (vendor/ghostty src/terminal/PageList.zig, "If
this blank row was a wrap continuation"; still so on upstream main at
108d503ac). The core ends the line there. Reported for review in
docs/upstream/ghostty-reflow-joins-a-blank-continuation.md (vt-core.md
§VC14).
