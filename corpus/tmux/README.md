# tmux, version by version

One folder per tmux: each release from 2.7 to 3.8 built from its
tarball, and each distribution's own package. What each file holds, how
they are made and what they show: `docs/tmux-versions.md` (TV2). Made by
`app/tests/tmux-versions/releases.sh` and `distros.sh`; do not edit.
`diff -r 3.4 3.5` is what changed between two.
